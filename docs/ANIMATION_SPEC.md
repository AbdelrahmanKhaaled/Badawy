# Animation Spec
**Preloader "The Camera Awakens"** (`CinematicPreloader`, ~3.9s incl. iris wipe; GSAP timeline): copper glow + lens ring draw → 6 SVG aperture blades rotate open (each pivots on its own ring point) → logo focus-pull 0.85→1 with blur → letter-staggered wordmark/subtitle → aperture expands, CSS radial mask iris reveals hero (`--r` tween). Hero + header entrances start on the `badawy:reveal` event as the iris opens. Scroll locked via `html.preloading`. Session flag `badawy-intro` (sessionStorage) skips it on later loads; inline head script prevents flash. 6.5s failsafe; reduced-motion = short fade.
**Declarative scroll layer** (`MotionProvider`): `data-reveal` (up/left/right/scale/fade/mask), `data-stagger` + `data-item`, `data-lines` (masked line reveal), `data-draw(-y)`, `data-parallax`. Initial hidden states exist only under `html.js`; `html.no-anim` (reduced motion or any failure) forces everything visible.
**Hero**: bg zoom-out, eyebrow, masked headline lines, copper light sweep on "STORIES", description, CTA spring; slow drift, REC-dot pulse; scroll parallax/fade.
**Other**: diagonal mosaic hover (clip-path), services/cards hover, works hover + lightbox, counters (once), testimonial carousel (Motion `AnimatePresence`), CSS marquee (<lg, seamless, pause on hover), cursor follower with "VIEW", scroll progress, back-to-top, animated mobile menu.
